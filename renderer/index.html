AUTOMATIC SERVERS
Auto start / stop

Starts a server when a tab in its language opens. Stops it after the last one closes.

Idle shutdown

Wait before stopping, so quick tab switches don't restart the server.

Multi-server mode

Keeps the servers you pin running, even when their tab isn't open.

Install location
<app>\servers\ · <app>\runtimes\

Downloads come from the language catalog, pinned to a version and checked against a SHA-256 hash.

ADD A LANGUAGE
  1. Open the Server Manager

    It lists every supported language with one-click installs.

  2. Click Install next to the language

    The server downloads into \servers\<language>\, is checked against its SHA-256 hash, then unpacks.

  3. Check the runtime

    Running code needs the language itself. Bundled ones are ready; others have a Download button or a link to the official installer.

  4. Not listed? Add a profile

    Copy any file in languages\, change the name, extensions, run command and server, then restart the app. Or request it so it gets added to the catalog.

LEARNING MODE

Learning mode runs every script inside Windows Sandbox: a clean, offline copy of Windows that is thrown away when the script ends, so nothing can change this PC, your files, the network or Active Directory.

Windows Sandbox isn't turned on for this PC yet. Turning it on needs an administrator and a restart, and the PC's virtualization must be enabled in BIOS (it usually is).

SETUP

Pick what to install. Everything goes into this app's own folder, no admin rights needed. Each download is checked against the vendor's published SHA-256 when one exists. You can change this later in Servers.
